# 声影工坊 2.0 · 网页版

浏览器里跑的音频提取 / 剪辑工具，引擎是 ffmpeg.wasm 0.12.10（单线程核，无需跨源隔离）。
**文件不离开设备**：读文件、解码、转码、下载全在浏览器里完成，没有后端。

## 文件

| 文件 | 说明 |
| --- | --- |
| `声影工坊-2.0有skill.html` | 单文件版，约 41 MB。CSS / JS / ffmpeg.wasm（base64 内联）全在这一个文件里，双击即可离线使用，不发任何网络请求 |

## 用法

- **电脑**：Chrome / Edge / Firefox / Safari 直接双击打开
- **安卓**：用文件管理器点该文件，选「用浏览器打开」（Chrome 地址栏不允许输入 `file://`）
- 首次打开需要解码约 32 MB 引擎，页面会空白 1–2 秒，属正常现象

## 功能

- 视频 → 音频提取（mp3 / m4a / flac / wav 等）
- 音频剪辑：裁剪、淡入淡出、音量、拼接
- 全程离线：无网络权限、无广告、无统计、无第三方依赖
